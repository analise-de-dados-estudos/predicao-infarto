# referencias/

Material de apoio: artigos, PDFs, diretrizes e documentação consultada.

Guarde aqui o que sustenta as afirmações do relatório — principalmente as
clínicas ("colesterol acima de 240 mg/dL é considerado alto"). Afirmação de
saúde sem fonte é opinião.

## Sugestões de fontes

| Fonte | Uso |
|---|---|
| [Sociedade Brasileira de Cardiologia](https://www.portal.cardiol.br) | Diretrizes brasileiras de prevenção cardiovascular, faixas de referência |
| [DATASUS / TabNet](https://datasus.saude.gov.br/informacoes-de-saude-tabnet/) | Números de internação e óbito por infarto no Brasil (contexto da introdução) |
| [OMS — Doenças cardiovasculares](https://www.who.int/health-topics/cardiovascular-diseases) | Estatísticas globais e fatores de risco |
| [Documentação do scikit-learn](https://scikit-learn.org/stable/) | Referência das técnicas de modelagem |
| [UCI Heart Disease](https://archive.ics.uci.edu/dataset/45/heart+disease) | Base clínica real e sua documentação |

## Como citar

Mantenha um arquivo `bibliografia.md` com as referências no formato pedido pelo
curso (ABNT, normalmente), incluindo data de acesso para conteúdo da web.
